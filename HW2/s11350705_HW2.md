# s11350705_HW2 實作說明

#開發流程
1. 檔案結構：建立 `css/`, `js/`, `assets/`，並將 HTML 命名為 `s11350705_HW2.html`。  
2. 版面設計：以 CSS Grid 完成月/週兩種顯示（週視圖為 7 欄 × 48 列，30 分鐘一格）。  
3. 今日標記：依作業要求，將「2025/10/03」固定為今日並加上外框與底色。  
4. 天氣背景：預設地點為東海大學；以 `<body>` 加上 `weather-sunny/cloudy/rainy` 切換背景（本次為靜態顯示）。  
5. 行事曆顯示空間：  
   - 月視圖：每格至少兩行文字供課表/備註。  
   - 週視圖：事件使用 `grid-row` 依起訖時間（30 分鐘為單位）產生連續底色，表示跨時段。  
6. JS：使用原生 JS 完成「月/週」顯示切換；前/後月按鈕僅視覺呈現（提示訊息）。  
7. 響應式：寬度小於 980px 時將佈局改為單欄。
